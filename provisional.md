# Listado de funcionalidades del proyecto

Digital Showcase llamado Aura Estética

## Listado de Funcionalidades

Del lado del comprador:

Catálogo interactivo de servicios: Un escaparate visual con buscador, filtros por categoría (tratamientos faciales, corporales, cuidado personal, servicios de transporte) y paginación para explorar las opciones.

Página de detalle del servicio: Vista dedicada para cada tratamiento con imágenes y videos explicativos, precio de referencia, beneficios, duración del procedimiento y un botón directo para solicitar información o agendar una cita.

Módulo de agendamiento y contacto: Formulario intuitivo para solicitar citas o cotizaciones ingresando los datos personales y el horario preferido para la atención.

Página de confirmación y seguimiento: Pantalla de confirmación tras enviar una solicitud, acompañada de un correo electrónico automático de bienvenida y resumen de la consulta enviada.

Asistente virtual flotante: Chatbot integrado y funcional con enlace a WhatsApp para responder dudas comunes de forma inmediata y conectar al usuario directamente con la clínica.

Del lado del administrador: 

Panel protegido de gestión de catálogo: Panel de control con inicio de sesión seguro para crear, editar y eliminar los servicios ofrecidos, con la capacidad de subir imágenes o videos de alta calidad de los tratamientos.

Gestor de solicitudes de citas y contactos: Listado centralizado de todas las solicitudes de información o reservas recibidas a través del formulario, mostrando sus datos de contacto y el estado de cada una (ej. pendiente, contactado, agendado).

Gestión de categorías y servicios especiales: Opciones para organizar los tratamientos por especialidades (faciales, corporales, cuidado personal) y gestionar la visibilidad de los servicios complementarios, como el transporte de pacientes.

## Stack Técnico 

 Frontend y backend: Next.js con App Router y TypeScript.
  - UI: Tailwind CSS + shadcn/ui.
  - Base de datos, autenticación y almacenamiento: Supabase.
  - Despliegue: Vercel.
  - Correos: Resend + React Email.
  - Traducciones: next-intl.
  - Formularios y validación: React Hook Form + Zod.
  - Analítica: Plausible con eventos personalizados.
